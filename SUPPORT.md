# Support (`SUPPORT.md`)

## Getting Help
- **Documentation:** Start with `README.md`, `REPLICATION.md`, `docs/index.md`, and `docs/faq.md`.
- **Bugs, Math Issues & Verification Questions:** Open a GitHub Issue at `https://github.com/0thernes/secmesh-pqsi/issues` using the provided issue templates and appropriate finding-class label (`bug`, `error`, `issue`, `problem`, `concern`, `dilemma`, `conflict`, `gap`, `hole`, `blindspot`).
- **Security Disclosures:** Follow `SECURITY.md` (`0_0@0thernes.art`).
- **Scope Note:** This is an independent open-science research project maintained on a best-effort basis without commercial SLA guarantees.
